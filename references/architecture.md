# 架构说明

## 分层与调用方向

```
DOM / 事件
   ↓ onXxx() 只做：改数据 → save() → refreshAll()
统一入口 refreshAll()
   ↓ 按固定顺序单独调用
渲染层 renderToday / renderBoard / renderRoster / renderGrowth
   ↓ 只读，不写存储
计算层 overall / scopes / statsOf / taskBuckets / relationSvg / ringSvg / barsSvg
   ↓ 纯函数
数据层 load / save / normalize / adoptCloud / mergeById
   ↓
localStorage（主存） + 可选 HostDB（镜像）
```

- 调用关系必须是有向无环图。**渲染函数之间严禁互调**：`renderBoard()` 不能调 `renderToday()`，反过来也不行。两者互相调用在语法上完全正确，但运行时栈溢出，静态检查拦不住。
- 所有联动走 `refreshAll()`：它先拼「今天要处理」（永远置顶），再按当前视图拼对应模块，最后一次性写入容器并同步导航高亮与日期输入框。
- 计算层只返回数据对象，不碰 DOM、不调 `save()`。这样同一份聚合结果可以被表格、汇总行、图表复用，口径天然一致。

## 存储

- 主键：`CONFIG.storageKey`，默认 `ws_generic_v1`。换场景必须改名，避免与同源其它页面串数据。
- `load()` 在 localStorage 为空时写入 `seedData()` 并返回；`normalize()` 只补缺失字段，**绝不覆盖用户已有数据**，因此旧版本数据可以平滑升级。
- 按日期的数据（`progress[date]`）与长期配置（`targets` / `goals` / `headcount`）分开存：日期切换只换视图，不动配置。
- 每次 `save()` 先写本地成功，再异步镜像到云端；云端失败静默降级为「本地模式」，本地数据不丢。

## 可选云同步适配器（HostDB）

宿主页面若注入：

```js
window.HostDB = {
  get(key) { /* -> Promise<string|null> */ },
  set(key, value) { /* -> Promise<void> */ }
};
```

则模板启用双向镜像；不注入就完全离线运行。契约要点：

1. `get` 返回字符串或 `null`，`null` 表示云端尚无记录，此时保留本地数据。
2. `set` 失败或超时不抛到界面，只把状态切成「本地模式」。
3. 冲突合并用 `mergeById(local, remote)`：按 `id` 去重，**双方新增都保留**；字段级冲突以远端（最新写入）为准。
4. 防抖 350ms，避免连续输入产生大量请求。
5. 同步状态展示四态：已同步 / 同步中… / 待同步 / 本地模式。

模板本身不绑定任何具体云服务、账号体系或网络地址。

## 备份与恢复

- 首屏常驻「导出 JSON 备份」「导入恢复」「清空示例数据」。
- 导出的是完整 `STATE`，导入经 `normalize()` 补齐字段，**不设条数上限**，可容纳上千条。
- 导入前不改动现有数据；解析失败只提示，不落库。
- 「清空示例」「删除条目」均需二次确认。
- CSV 导出带 UTF-8 BOM，避免用电子表格软件打开时中文乱码。

## 汇总口径（最容易出错的地方）

- **汇总不能把当前筛选后的行相加**。看板可切「按分组 / 按负责人」，后者只覆盖已关联负责人的成员；未关联成员会被漏掉。
- 正确做法：汇总行调用 `overall()` 直接遍历全量 `STATE.members`，目标取所有分组目标之和，与当前切换维度无关。
- 汇总行/卡的口径要写进界面提示（例如「共 N 人 · 全量口径」），让读表的人能核对。
- 缺口类指标一律 `max(0, 目标 − 当前)`，超出部分单独列示，不出现负数。

## 规模与增量写入

- 一次最多 3-4 个模块。超出先分期：本期核心 3 个，后续每期追加 1 个，且新模块用新存储字段，不动旧数据。
- 单文件超过约 60KB 时，先写骨架（HTML / CSS / CONFIG / 数据层 / 计算层 / 占位符 / 统一刷新入口），再逐个替换占位符补模块。每补完一个模块，文件仍是能跑的中间态。
- 占位符用精确唯一串（如 `/* MODULE_BOARD */`）；校验时也精确匹配，短串会误命中常量前缀。

## 响应式

- <920px：侧栏变抽屉 + 遮罩，内容单列；≤380px 关系图降为单列。
- 宽表横滚时 `position:sticky; left:0` 冻结首列，背景必须不透明，并给汇总行单独覆盖底色，否则会被明细行的背景盖掉。
- 输入框移动端字号 ≥16px（防 iOS 自动放大）；按钮 ≥44×44px；底部留 `env(safe-area-inset-bottom)`。
- 数字输入用 `type="number"`。

## 交付前自检清单

1. 调用链无环（画出函数关系确认没有 A→B→A）。
2. 初始化链路通畅，被调用函数均已定义。
3. 所有 `getElementById` / `querySelector` 目标存在于 HTML。
4. localStorage 为空能填示例数据；清空示例后不报错。
5. 日期边界：跨月、跨年、闰年正确（用 `Date.setDate()`，不要手算天数）。
6. 事件绑定在 DOM 就绪后执行。
7. 无全局变量冲突，循环内闭包变量正确捕获。
8. 模块数 ≤ 4；超限已分期；超大文件已按骨架 + 增量写入完成。
9. 全文零外链、零真实姓名 / 组织 / 地域 / 凭证 / 内部地址。
10. 汇总行与汇总卡数量正确，切换维度后数值不变。
