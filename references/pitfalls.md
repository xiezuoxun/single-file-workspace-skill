# 实测踩坑清单

这些都是语法正确、静态检查拦不住，只有跑起来才暴露的问题。

## 布局

1. **flex-wrap 容器里最后一行的单卡会被撑大**：`flex:1 1 158px` + `flex-grow` 让只剩一张图的行占满整行，内部 `height:auto` 的 SVG 跟着放大。要严格等尺寸，用 `display:grid; grid-template-columns:repeat(2,minmax(0,1fr))` 固定列数 + 卡片定高 + SVG 定高。
2. **图表半径随数据量变化会显得不整齐**：固定画布 `viewBox`、固定半径 `R`、节点按 `(i/n)*2π` 均匀分布；不要给半径加随机抖动。正上/正下的节点文字按序号奇偶分左右，保持对称。
3. **冻结列背景被覆盖**：`position:sticky` 的首列必须给**不透明**背景；汇总行还要单独写一条更高特异性的规则，否则明细行的 `var(--surface)` 会把汇总底色盖掉，横滚时看着像内容穿透。
4. **中文首列被挤成竖排**：不是 `writing-mode` 问题，是宽表把列宽压到十几像素。给首列 `min-width:92px` + `white-space:nowrap` 即可。
5. **iOS 自动放大页面**：输入框字号 <16px 时 Safari 会缩放整个页面。移动端统一下 `input,select,textarea{font-size:16px}`。

## 交互与状态

6. **每敲一个字输入框就失焦**：把 `handleInput` 绑在 `input` 事件上并每次 `refreshAll()` 重建 DOM 就会这样。改用 `change` 事件，或只更新局部节点。
7. **整体替换冲掉用户后填的字段**：定时导入 / 批量同步如果把整份对象 `replace` 掉，而来源只有基础字段，用户后来补的扩展列和手工新增记录会被每天清空。改成 `merge`：更新基础字段、保留扩展字段、保留本地独有记录。
8. **汇总按筛选后的行相加会漏数据**：切换分组维度时，某些成员不属于任何当前 scope（例如未关联负责人），累加结果会少人。汇总一律基于全量数据独立计算。
9. **占位符校验误报**：用短串做「占位符已清空」检查时会命中同前缀的常量名。用精确完整串匹配。
10. **空数据崩溃**：清空示例 / 首次打开 / 导入空文件都要能渲染。所有聚合用 `|| {}` / `|| []` 兜底，分母为 0 时率值返回 0。

## 日期与数据

11. **日期边界**：跨月、跨年、闰年不要用天数手算，用 `Date.setDate()` 让引擎处理；格式化时月份要 `padStart(2,'0')`。比较日期字符串用 `YYYY-MM-DD` 字典序即可。
12. **负数缺口**：`目标 − 当前` 可能为负，界面要么归 0，要么单独显示「超出 N」，不要把负数直接写进 KPI。
13. **CSV 中文乱码**：导出时加 UTF-8 BOM；解析时先剥掉 BOM 再处理。带逗号/引号的单元格要做转义解析。
14. **JSON 导入带 BOM**：`JSON.parse` 会直接失败，先剥掉 BOM 再解析，且解析失败不能改动现有数据。

## 工程与验证

15. **外部依赖 404 导致功能全废**：页面一旦被另存为本地文件，任何 CDN 脚本 / 字体 / 图表库都会加载失败。全部内联，图表手写 SVG。
16. **vm 渲染桩访问不到顶层 `let/const`**：它们不会挂到 context 对象上。把测试代码拼进同一段脚本一起执行，才能访问这些变量。
17. **渲染桩被真实渲染函数带崩**：调用前把会写 DOM 的函数覆盖成 noop，或直接只调返回字符串的渲染函数，别触发完整初始化。
18. **全局静态检查误命中别的视图**：负向断言要切片到目标函数体内查，不要全文 grep 一个通用词。
19. **发布后还是旧内容**：重新导入 HTML 之后必须显式执行发布/同步，导入本身不会刷新已发布的产物；产物目录可能带随机前缀，核验前先拉清单再拼下载地址。
20. **环境变量与管道**：某些精简 shell 没有 `tail`/`head`，给 Python 输出接管道会让 stdout 提前关闭并报错。直接输出即可。
